Usage: java -jar sftp-uploader.jar <chemin-fichier>

old format:
sh-keygen -p -m PEM -f tecal_rsa 

Java class for sending file to a SFTP server.
Use file config.ini such as:

[sftp]

host= XXXX.YYYYY.com

port=32

username=TOTO

password=XXXXXXXXXXXXXX

remoteDir=in

[retour]
code_retour=-1

message=RAS
